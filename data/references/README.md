# 参照テキスト一覧

大賀屋呉服店「おおがや着物チャンネル」（YouTube）の動画内容を
NotebookLM でエッセンス抽出・整理したテキストファイル群。

レッスン設問の作成と照合に使う。

- アプリ生成（`lib/prompt.ts`）が該当ファイルを初稿に載せる
- create-lesson-questions のレビュー・修正で事実を照合する
- ガイドが正。参照は事実の根拠。語や出題範囲はガイドに従う
- `kakuzuke-youfuku-hikaku.txt` は生成に載せない（相当する洋装の誘発を避ける）
- 対応は現行のコース／レッスンID。旧「レッスン1（第一礼装）」番号は使わない

## 追加方法

1. NotebookLM でテキストを抽出する
2. このフォルダに `{テーマ略称}.txt` として保存する
3. このREADMEのテーブルに1行追加する
