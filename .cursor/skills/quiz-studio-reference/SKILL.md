## Quiz Studio とは

AI-Driven School 運営（Surprise社）が社内で使うローカルの問題制作ツール。本気AIドリルの問題を作るために開発された。

| 項目 | 内容 |
|------|------|
| 起動 | `pnpm dev`（ローカル。サーバー公開なし） |
| 技術スタック | Next.js + shadcn/ui + Tailwind CSS + Anthropic Agent SDK |
| 規模 | 1シリーズ 600〜700問。1〜2週間で1シリーズ完成 |
| 使用者 | 運営チームのみ（複数人で各自のPCで使用） |

## UI 構成（4 要素）

### 左パネル — CONTENT

- シリーズ一覧（カラーアイコン・公開/下書きバッジ・Nコース数）
- シリーズを展開 → シリーズガイド / シリーズテスト / コース一覧
- コースを展開 → レッスン一覧（Nレッスン数・状態ドット）
- 下部に「追加」ボタン群（シリーズ・コース・レッスン追加）

### 上部タブバー

ブラウザタブ風にコース/シリーズを複数同時に開ける。

### 中央パネル — メインコンテンツ

コースガイド、品質バナー、問題カード（難度・PASSED/FAILED・承認）、ビジュアル挿絵、再レビュー／テスト実行。

### 右パネル — Agents Bar

フリーチャット（スキルセレクター）＋ 品質レビュー / クイズ作成。スキルを選んでセッション開始。

## コンテンツ階層（本家）

```
N シリーズ
└─ シリーズガイド
└─ シリーズテスト
└─ N コース
   └─ コースガイド
   └─ N レッスン（本家は 8〜12問）
      └─ 各問題（四択 or ○×）
```

呉服Quiz工房の問数は本家の 8〜12 に合わせない。コースガイド `question_counts` が正。

---

## 問題作成フロー（本家・レッスン1本）

1. シリーズガイド作成（grill-me → 承認/修正）
2. コースガイド作成
3. レッスン下書き生成（シリーズ＋コース＋承認済み前レッスン）
4. 機械チェック
5. AI サブエージェントレビュー（並列・問題単位）
6. 批判的ユーザー視点レビュー
7. 修正 → 更新した問題のみ再レビュー
8. 全問合格 → 承認

AI が工程を自己判断で飛ばさないよう、各ステージにフックがある。

## コンテンツ設計哲学（本家）

| 原則 | 内容 |
|------|------|
| 同一メタファー | 1概念 = 1比喩。「Gitのコミット = セーブポイント」なら他の表現は不可 |
| 復習の自然な組み込み | 復習レッスンは作らない。過去の概念が次で再登場する |
| 復習頻度の計測 | 1概念が何回・いつ再登場するかを数字で管理 |
| 上流は人間が書く | ガイドの叩き台は AI、詰め切るのは人間 |

## 機械チェック（本家の推定 / 工房の実装）

本家（推定）: 禁止語、問題数 8〜12、文字数、四択/○×形式、解説。

工房（実装・`lib/inspect.ts`）:

- 設問数が `question_counts[lessonIndex]` と一致（未宣言は不合格）
- 四択は選択肢4・正解 0〜3。正解だけが他より8文字以上長いと不合格
- ○×は `answer` が boolean
- 解説必須
- 禁止語: フォーマル度・ドレスコード・ランク・レベル・格式・ステータス・燕尾服・タキシード・カクテルドレス

## 現在地（Graduation-work）

- 技術: Next.js 16 + Tailwind CSS 4 + Anthropic Claude API（`claude-opus-4-5`）
- 実行時データ: SQLite（`data/app.db`）+ Drizzle ORM
- seed 元: `data/kakuto-tpo/` JSON。`pnpm seed` は DB を DROP する
- 対象: 令和きもの販売員ドリル。シリーズ「品目の格とTPO」。5コース × 各3レッスン
- 問数: コース1 は `[8, 8, 4]`（確定）。コース2〜5 の `[8, 8, 8]` は仮置き。生成前に問数を確認する
- スキル: `.cursor/skills/` に上記6本
- 起動: `pnpm dev` → http://localhost:3000
- 生成ロック: 同一コース内の前レッスンが approved になるまで

| 項目 | 呉服Quiz工房（現在） | Quiz Studio（目標） |
|------|---------------------|---------------------|
| シリーズ数 | 1 | N |
| DB | SQLite + Drizzle（稼働中）。JSON は seed | SQLite + Drizzle |
| AI | 直接 Claude API | Anthropic Agent SDK |
| サブエージェントレビュー | なし（チャット側スキルで代替） | あり（並列・問題単位） |
| Agents Bar | なし（後回し） | 右パネル |
| 問題数/レッスン | `question_counts`（固定ではない） | 8〜12問 |
| UI | Tailwind のみ・3ペイン | shadcn/ui + Tailwind・4要素 |
| ビジュアル挿絵 | なし | 問題内に図解 |
| シリーズテスト | なし | あり |
