# 設問レビュー詳細

`SKILL.md` STEP 4 から読む。固定認識は [locked-principles.md](locked-principles.md)。

各設問を、**出題者とは別人格**として読む。ガイドもレッスン意図も知らない。問題文→選択肢→正解→解説の順に、文面だけを見る。別人格で土台が通じていない設問は、他がよくても FAIL である。FAIL が1つでもあるセットは出さない。

---

## 評価観点

| 観点 | 基準 |
|------|------|
| **意味の通じ** | 別人格で、誰が・どこで・何について話しているかが文面だけで立つか |
| **出題範囲** | このレッスンの `lesson_roles` と `lesson.title` に沿うか。標語化していないか |
| **内容の正確性** | 正解・解説が呉服の知識として正しいか。ガイドと参照が矛盾したらガイドが正。参照にない情報は出典を疑う |
| **問いと正解の軸** | 聞いていることと正解が同じ軸か |
| **答え漏らし** | 問題文が正解の手がかりを先に置いていないか |
| **学習者視点** | 売場の知識・判断を問うか。ドリル設計や規定演技／自由演技の名称要求は FAIL |
| **導入順序** | 後の補助語を出していないか |
| **語の限定** | `writing_style` どおりか。売場。「選択品」「アイテム」なし。コース1は裸の「格」だけで問わない |
| **選択肢の品質** | ダミーが現場でありそうな誤りか。4文は同じ構文・同程度の長さ |
| **解説の質** | なぜ正しいか。仮説は立ててよい、を補っているか。未導入の語で説明していないか |
| **重複** | 同レッスン内の実質同一問、コース内の同じ固有シナリオの繰り返し |
| **難易度** | 宣言問数の全体で易・中・難が偏っていないか。水増しで稼いでいないか |
| **接客場面** | 少なくとも一部がお客様との場面を想起させるか。土台知識の混在は可 |

## 意味の通じ（別人格）

出題者の頭の中にある前提は、文面に無いものとして扱う。学習者はガイドを読んでいない。

問題文だけを初めて読んだとき、次が言えるか。

- 誰が話しているか（売場のお客様か、同僚か）
- どこで、何の用件か
- 「出る」「見る」「要る」が、参列なのか装いなのか
- 正解は、その文面に対する答えになっているか

一つでも、ガイドや作者のメモを足さないと取れなければ FAIL。

**FAIL**: 「黒留袖を持っていないのですが、結婚式に出られますか。」
誰の発言か、売場か、出るとは参列か装いか、持っていないと何が困るのかが取れない。

**通しの型**: 「呉服売場で、弟の結婚式に参列するお客様が『親族の列席は色留袖と家の本に書いてあった。色留袖を用意すればよいですね。』と言った。」

○×も同じ。主語と場面が無い断言は FAIL である。

新しいセットを出すとき、各問の別人格判定を先に書く。指示の一面を標語の問いに縮めた疑いがあれば、出す前に止める。

## 伺う中身

「伺う」なら何でも正解、ではない。生成が呉服の早見表に飛びつくなら、その問いは狙いに近い。

正解の伺いと、ダミーにする決めつけは [locked-principles.md](locked-principles.md) を使う。シリーズの「場・規模・意向」と、設問軸の「会場・雰囲気・TPO・和装にしたい理由」と、短い正解文「場所や雰囲気を伺ってから見立てる」は同じ伺いの長短であり、別正解ではない。

地図レッスン3の確定例（正解は **2**。JSON `correct` は `1`）:

- 問題文: 呉服売場で、弟の結婚式に参列するお客様が言った。「親族の列席は色留袖と家の本に書いてあった。色留袖を用意すればよいですね。」販売員の答えとして近いものはどれか。
- 1. 家の本の通り、色留袖一択で用意する。
- 2. 場所や雰囲気を伺ってから見立てる。
- 3. 着用頻度から、色留袖は勧めない。
- 4. 好きな装いでよいと決めてよい。

## 安易なダミー

「価格が高ければよい」「一番高い品を出せば足りる」は一目で除外できる。

**FAIL**: 価格ダミーを同じレッスンで2つ以上。コース内で同じ型を繰り返すのも FAIL。上限は宣言問数で多くても1問。無くてよい。

代わりに、知識として正しく見えうる決めつけを置く。続柄なら一択、既婚未婚で品目が決まる、着用頻度、家の本通り、決まりは古いので捨ててよい、好みがあれば場は見なくてよい、洒落ものなら制約はない。

○×で「高価なら決まりの多い席に用いてよい」と問うのも価格ダミーと同じ型である。

## 規定演技／自由演技

[locked-principles.md](locked-principles.md) の定義に従う。

**設問で問うこと**: 決まりはあるが本質は敬いであること。洒落ものにも取り合わせの制約があること。ファッション延長は対象外であること。決まりの多い装いが要るか、洒落もので足りるか。

**設問で問わないこと**: 「これを何と呼ぶか」「規定演技と自由演技のどちら寄りか」（名称を答えさせること）。

**FAIL**: 「規定演技と呼ぶ。」「この場は規定演技」を正解にする。直しは論理を問う（窮屈に見えても敬いを装いで示す／形式は緩いが何でもよいわけではない）。

## ドリル設計メタ問い

ガイドの `lesson_roles` / `must_include` / `revisit` / `exclude` は出題者のメモである。そのメモ自体を学習者に問うな。

問題文・選択肢から「このシリーズ／このコース／このレッスン／この地図」と、配置の語（どう扱う・どう位置づける・押さえる範囲・再登場・題材）を外す。売場の知識として成立しなければ FAIL。成立しても、正解やダミーが「カリキュラム上の置き場」なら FAIL。

**赤旗**（問題文・選択肢。解説は次項）:

- このシリーズ／このコース／このレッスン／この地図／このドリル
- どう扱うか／どう位置づけるか（著者の配置）
- 押さえる範囲／再登場／題材として
- 唯一の補助語／唯一のメタファー（設計宣言として聞くとき）

**解説は例外**: 「具体的な運用は後のコース」は先送りの注記として可。問題文・選択肢でそれを正解やダミーにしない。

**導入順序との違い**: 導入順序は、まだ出していない語を出さないこと。本観点は、語が出ていても「このドリルではこう置く」を問わないこと。

「このコースではどう扱うか」を「どう位置づけるか」に言い換えるだけでは FAIL のまま。

| 型 | 悪い例 | 直し |
|---|---|---|
| 設計のレンズ選定 | 「このシリーズの唯一の補助語はどれか。」「規定演技と呼ぶ。」 | 場面で、決まりの多い側の本質か、自由側の限度を問う |
| コースへの配置 | 「五つ紋の色留袖は、規定演技としてどう位置づけるか。」 | 「五つ紋の色留袖は、どの装いの代表か。」 |
| レッスンの立場 | 「このレッスンの立場として正しいものはどれか。」 | 決まりそのものの理由を問う |
| 地図の範囲 | 「紋や帯・小物を、この地図コースで押さえる範囲はどれか。」 | 「今日の見立てで、紋や帯・小物まで手順を決めるか。」 |

「この場はどちら寄りか」の「この」はお客様の場であり、赤旗ではない。

## レポート形式

設問ごとに、別人格判定を先に書く。正解番号は **1始まり**。

```
Q{N}（{four_choice|true_false}）: 別人格 PASS / FAIL
  誰/どこ/用件: {文面だけから取れること}
  正解: {1始まりの番号、または ○/×}
  内容: PASS / FAIL
  FAIL理由: {理由}
  修正案:   {問題文・選択肢・正解・解説}
```

```
---
合格: {N}問 / {宣言問数}問  要修正: {N}問
```
