# シリーズガイド作成スキル

1問ずつ質問してシリーズガイドの叩き台を作り、人間が確認してからAPIで保存する。
叩き台はあくまで素材。最終判断は必ず人間が行う。

---

## 前提確認

`GET http://localhost:3000/api/data` を実行する。

- 接続失敗 → `pnpm dev` の起動を促して停止する。
- 既存のガイド内容がある → 内容を表示して「上書きしてよいか」を確認してから進む。

---

## 質問ステップ（1問ずつ進める）

回答が薄い・曖昧な場合は「もう少し具体的に教えてください」と深掘りしてから次へ進む。

| # | 質問 | フィールド |
|---|------|----------|
| Q1 | 「このドリルを使うのは誰ですか？（役職・経験年数・どんな場面で困っているかを教えてください）」 | `target` |
| Q2 | 「このシリーズを終えた後、受講者は何を自信を持ってできるようになりますか？」 | `purpose` |
| Q3 | 「このシリーズで必ず登場させたいキーワードや概念を挙げてください（複数可）」 | `terms` |
| Q4 | 「このシリーズにおける『格』の定義・判断基準を教えてください。受講者がどう使うかも含めて」 | `dan_definition` |
| Q5 | 「使ってはいけない言葉・表現はありますか？（フォーマル度・ドレスコード・ランク・レベルはすでに禁止済みです。追加があれば）」 | `forbidden_synonyms` |
| Q6 | 「特殊ケースや例外として受講者に伝えたい呉服の知識はありますか？」 | `exceptions` |
| Q7 | 「問題文はどんな言葉づかい・トーンで書いてほしいですか？（例：ですます調・短文・体言止め）」 | `writing_style` |

---

## 叩き台の出力と確認

全 7 問の回答をもとに以下の形式で出力する。

```
【シリーズガイド 叩き台】

■ 対象者
{target}

■ 習得目標
{purpose}

■ 主要語句
{terms}

■ 格の定義
{dan_definition}

■ 禁止同義語
{forbidden_synonyms}（フォーマル度・ドレスコード・ランク・レベルを含む）

■ 例外・注意事項
{exceptions}

■ 文体・トーン
{writing_style}
```

出力後に確認する：
「このまま保存しますか？修正したい箇所があれば教えてください。」

修正があれば該当箇所を直して再表示 → 再度確認する（合格まで繰り返す）。

---

## 保存

「保存する」と承認を得たら API を呼ぶ。

```
POST http://localhost:3000/api/save-guide
Content-Type: application/json

{
  "type": "series",
  "guide": {
    "target":             "...",
    "purpose":            "...",
    "terms":              "...",
    "dan_definition":     "...",
    "forbidden_synonyms": "フォーマル度・ドレスコード・ランク・レベル（追加分があればここに）",
    "exceptions":         "...",
    "writing_style":      "..."
  }
}
```

保存完了後：
「シリーズガイドを保存しました。次は `create-course-guide` スキルでコースガイドを作成できます。」
