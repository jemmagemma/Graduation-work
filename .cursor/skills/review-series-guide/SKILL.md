# シリーズガイド レビュースキル

APIから現在のシリーズガイドを取得し、観点ごとに評価・改善案を提示してから保存する。

---

## 前提確認

`GET http://localhost:3000/api/data` を実行する。

- 接続失敗 → `pnpm dev` の起動を促して停止する。
- `series.guide` が空 → 先に `create-series-guide` スキルを実行するよう促して停止する。

---

## レビュー評価

現在のシリーズガイドを以下の観点で評価し、各項目に PASS / FAIL を付ける。

| 観点 | 基準 |
|------|------|
| **具体性** | 対象者・目的・格の定義が「誰でも同じ解釈ができる」レベルで具体的か |
| **整合性** | 各フィールドの内容が互いに矛盾していないか |
| **禁止語の網羅** | 禁止同義語が実際に問題文で使われそうな言葉を十分に列挙しているか |
| **スコープ明確性** | 何を「扱う」か「扱わない」かが明示されているか |
| **文体の指定** | 文体・トーンの指定が問題文制作者が迷わないレベルで具体的か |
| **例外の網羅** | 受講者が混乱しそうな例外・特殊ケースをカバーしているか |

### レポート形式

```
【シリーズガイド レビュー結果】

{観点名}: PASS / FAIL
  FAIL理由: {理由}  ← FAIL の場合のみ
  改善案:   {具体的な改善文案}  ← FAIL の場合のみ

---
合格: {N}項目 / 6項目  要改善: {N}項目
```

---

## 改善の確認と保存

FAIL 項目がある場合：
「{観点名} の改善案を採用しますか？修正したい場合は別案を教えてください。」

承認された改善をガイドに反映し、確認用に全体を再表示する：
「このまま保存しますか？」

「保存する」と承認を得たら API を呼ぶ。

```
POST http://localhost:3000/api/save-guide
Content-Type: application/json

{ "type": "series", "guide": { <改善済みの全フィールド> } }
```

保存完了後：
「シリーズガイドを更新しました。」
