# コースガイド作成スキル

シリーズガイドを参照しながら1問ずつ質問し、コースガイドの叩き台を作って保存する。
叩き台はあくまで素材。最終判断は必ず人間が行う。

---

## 前提確認

`GET http://localhost:3000/api/data` を実行する。

- 接続失敗 → `pnpm dev` の起動を促して停止する。
- `series.guide` が空 → 先に `create-series-guide` スキルを実行するよう促して停止する。
- コースは複数ある。対象コースを確認してから進む。既存ガイドがある場合は内容を表示して「上書きしてよいか」を確認する。

シリーズガイドの内容を確認・表示して、コースガイドの質問の文脈として使う。

---

## 質問ステップ（1問ずつ進める）

**質問を始める前に**、シリーズガイドの `purpose` を引用して確認する：

```
シリーズの目的は：「{series.guide.purpose}」

このコースはその目的のうち、どの部分を担当しますか？
（例：格の体系的な理解を担う／接客の判断軸を身につけさせる）
```

この確認を受けてから、以下の質問に進む。
回答が薄い・曖昧な場合は「もう少し具体的に教えてください」と深掘りしてから次へ進む。

| # | 質問 | フィールド |
|---|------|----------|
| Q1 | 「このコースの各レッスンはどんな役割分担にしますか？（例：レッスン1は〇〇、レッスン2は△△）。シリーズの目的『{series.guide.purpose}』に照らして、各レッスンが接客のどの場面に対応するかも教えてください」 | `lesson_roles` |
| Q2 | 「このコースで受講者に必ず理解させたい概念・知識は何ですか？」 | `must_include` |
| Q3 | 「前のレッスンで出てきた概念を後のレッスンに自然に再登場させたい場合、どの概念をどのタイミングで出しますか？」 | `revisit` |
| Q4 | 「このコースで扱わない・扱いたくない内容はありますか？」 | `exclude` |
| Q5 | 「このコースを修了した受講者の状態を一文で表すとどうなりますか？」 | `completion` |

---

## 叩き台の出力と確認

全 5 問の回答をもとに以下の形式で出力する。

```
【コースガイド 叩き台】

■ レッスン役割分担
{lesson_roles}

■ 必須内容
{must_include}

■ 復習の組み込み方針
{revisit}

■ 除外する内容
{exclude}

■ 修了後の姿
{completion}
```

出力後に確認する：
「このまま保存しますか？修正したい箇所があれば教えてください。」

修正があれば該当箇所を直して再表示 → 再度確認する（合格まで繰り返す）。

---

## 保存

「保存する」と承認を得たら API を呼ぶ。

```
POST http://localhost:3000/api/save-guide
Content-Type: application/json

{
  "type": "course",
  "courseId": "<対象コースのid>",
  "guide": {
    "lesson_roles": "...",
    "must_include":  "...",
    "revisit":       "...",
    "exclude":       "...",
    "completion":    "..."
  }
}
```

保存完了後：
「コースガイドを保存しました。次は `create-lesson-questions` スキルでレッスン問題を作成できます。」
